# 内容复盘方法论

> 2026-08-03 立。源头：小红书 31 篇后台导出 + 公众号后台的交叉分析，以及同日两次「自己的假设被自己的数据证伪」的经历。
> 与另两份标准的分工：**north-star 管"该不该做"（发布前）· voice-profile 管"怎么说像我"（写的时候）· 本文件管"发完之后学到了什么"（发布后）**。三者构成闭环。
> 北极星不变：**max(同频密度)，不是 max(流量)**。所以复盘的第一指标不是曝光。

---

## 一、认可阶梯：每种互动是不同强度的信号（起号阶段的第一指标）

作者自定（2026-08-03）：**起号阶段看互动质量，不看曝光。** 每种动作代表不同强度的认可——

| 动作 | 含义 | 强度 |
|---|---|---|
| 赞 | 看到了、还行 | 弱 |
| **收藏** | **这对我有用，我要照着做** | 中 |
| **转发** | **我认同，且愿意署自己的名分享给别人** | 强 |
| **评论** | **我愿意直接跟你互动** | 强 |
| **关注/涨粉** | **我认可你这个人和你后续的内容** | 最强 |

**算法：一律用「每 100 观看」的比率，不用绝对数**（绝对数被曝光量绑架，比率才反映单位读者的认可强度）。

配套的触达层指标（曝光、封面 CTR）只用来诊断**分发**，不作为好坏判据：
- 触达低 + 单位互动高 = **内容对，分发没打开**（不要改内容，去查分发）
- 触达高 + 单位互动低 = **纯噪音流量**（受众不对，这种爆款反而稀释同频密度）

**曝光与认可强度经常背离。** 实证（2026-08-03，31 篇导出，每 100 观看）：

| 篇 | 赞 | 藏 | 转 | 评 | 粉 | 深度互动合计 |
|---|---|---|---|---|---|---|
| 收藏=稍后读（662曝光，n小） | 8.2 | **8.2** | **5.5** | 0 | **5.5** | **19.2** |
| Agent命中率SOP | 6.1 | **12.7** | 0.9 | 0 | 0.9 | 14.5 |
| Claude一键脚本 | 4.2 | 7.0 | 3.2 | 0 | 0.5 | 10.7 |
| 安全帽 | 6.1 | 4.0 | 3.2 | 0.7 | 0.8 | 8.6 |
| 要不要让agent说话 | 6.6 | 3.9 | 0.6 | **2.8** | 0 | 7.2 |
| **她开会没带PPT（16.7万曝光）** | 3.3 | 3.8 | 2.5 | 0.2 | 0.4 | **6.9** |
| 家庭第一辆电车（1.65万曝光） | 0.4 | 0.2 | 0.03 | 2.1 | 0.09 | **2.4** |

四条由此确立的判断：

1. **爆款赢在量、不赢在质**：16.7 万曝光那篇单位认可强度 6.9，低于安全帽 8.6 和说话篇 7.2。绝对涨粉最高（141），但**单位读者的同频密度反而被稀释**。
2. **《要不要让 agent 说话》不是内容失败**：评论率 2.8% 全账号第一、赞率 6.6% 前列——**筛到的人互动意愿最强，只是仅 181 人看到**。诊断应为"分发没打开"，**不是"同题连发疲劳"**（该自我归因不被数据支持）。
3. **收藏归工具/SOP 类**：Agent命中率SOP 12.7%（第一）、Claude脚本 7.0%、收藏=稍后读 8.2%——**"藏"= 我要照着做**，所以能照着做的内容才吃收藏。
4. **评论要看质量不看数量**：《电车》评论率 2.1% 不低，但赞/藏/转/粉全线垫底（0.4/0.16/0.03/0.09）——那些评论是"哪个牌子好"式提问，不是认同。**高曝光 + 低认可 = 纯噪音流量。**

数据焦虑时回到这张表：问"筛到我要的人了吗"，不问"怎么改能更爆"。

## 二、发布前：预注册（这一步不做，复盘就是事后编故事）

发之前在复盘表里写下三行：

1. **过北极星五问**（目标函数/活证据/观点/命名/分界与入口），答不上就改到能答
2. **本次变量**：这篇跟上一篇比，我只变了什么？（一次只变一个，否则归因不可能）
3. **预测**：我预期哪一层指标会好/会差，为什么？

预测写在前面，数据回来才有"猜对了/猜错了"，认知才有增量。

---

## 三、发布后：取证

- **6h / 24h / 72h 三次快照**：曝光、CTR、观看、互动、涨粉。
  （后台导出表**没有时间序列**——这是目前分离"早期社交助推 vs 内容自身力量"的唯一办法，缺了就永远只能猜。）
- **评论区逐条看**：谁在说话、说了什么。**这是唯一能直接看到"筛到了谁"的地方**，比任何数字都接近北极星。
- 记录社交侧：@了谁、对方是否互动（及互动发生的时间点）。
- 记录外力：是否投流、官方话题、发布时段。

## 四、复盘纪律（硬约束）

1. **多变量摊开再归因**，四维必查：①内容侧（钩子类型/篇幅/图文比）②社交侧（@谁、大V是否互动）③平台机制（小红书=推荐制·分池升级；公众号=订阅转发制·无推荐池）④外力（投流/话题/时机）。**禁止单因素归因。**
2. **每条结论标置信度 + 样本数**；n=1 一律标「待验证」。
3. **被证伪的旧判断保留并标注证伪过程，不要删**——"我原以为 X，数据说不是"本身就是最好的选题燃料。
4. **缺数据就去要数据，不用推理填补空白。**
5. 复盘的目的是**优化选题判断**，不是优化爆款率。与北极星冲突时，北极星优先。

## 五、当前已确立的结论（随证据修订）

| 结论 | 置信度 | 证据 |
|---|---|---|
| 教程型标题一律低 CTR（"全攻略/全流程/N个技巧"） | 高 | RAG全攻略 6.2%、Agent设计全流程 7.4%、Anthropic六技巧 6.4% vs 具体冲突型 15–20% |
| 封面 CTR 不是破池瓶颈 | 高 | 扑街篇 CTR 15.0%/14.3%，远超账号中位数 ~8%，仍只有 5456/1122 曝光 |
| @大V 无独立流量效果 | 较高 | 三篇均 @Zara，两篇分别只有 5456/1122 曝光 |
| 平台形态适配：小红书吃现场图文、公众号吃观点长文 | 中 | 同内容交叉：34109 vs 181；5151 vs 180 |
| 差距发生在「小池→大池」升级环节 | 中 | 扑街篇互动/观看 13.9%、13.8%，**高于**爆款的 9.8%，却拿不到曝光 |
| 受众宽度决定能否升级（泛人群可懂 vs 需行业背景） | **待验证** | 篇二《10倍的个体，1.2倍的组织》为对照实验 |
| 大V收藏是结果而非原因 | **待验证** | 缺时间序列 |

## 六、维护

每次复盘产出与本文件冲突或印证的实证，回写修订——**标准跟着证据长，不靠拍脑袋改**。被推翻的条目移入"已证伪"并注明推翻它的数据。
