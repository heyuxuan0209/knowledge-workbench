# AI 观察手记 · 系列模板规范

> 精读硅谷一线 builder 的一手内容（YouTube / X / Blog）＋ 记录参加的 AI 大会现场与嘉宾精讲（飞书 AI 大会、黑客松等）。
> 系列名「AI 观察手记」为占位，可改。本规范面向未来沉淀进创作台。

## 一、设计原则：共识骨架 + 可换皮肤 + 配套文案

- **共识特色（每期不变）** → 系列辨识度：读者一眼认出。
- **配色皮肤 + 文案风格（按内容换）** → 泛化：适配 builder 视频 / X 长文 / 大会现场 / 黑客松。

## 二、共识特色（不变项，所有风格共用）

1. **内刊报头**：`AI 观察手记 ┃ JOURNAL` + 双线/单线分隔（骨架 = opt1）。
2. **来源徽章**（左上 kicker 处，**可换 / 可留空隐藏**）：`▶ YouTube` / `𝕏 Twitter` / `✎ Blog` / `🎧 播客` / `🎤 现场·<大会名>` / `⚡ 黑客松`。`content["badge"]=""` 即整枚移除，来源仍由右上 `issue_event` 与底部作者行交代，不丢信息。
3. **标题关键词下划线**：一处、彩色、点睛。
4. **期号 + 场合**：`NO.05 · <来源/场合>`（右上）。
5. **底部作者行 + 类型标签**：`<演讲人> · <身份>` ｜ `<深度精读 / 现场手记 …>`。
6. **双尺寸**：2.35:1（消息列表 900×383）+ 1:1（转发卡片/主页 1000×1000），各自专门排版，非裁切。

## 三、风格预设（头图配色 ↔ 文案风格 配对）

**当前启用两套**（去来源徽章）。每套 = 头图皮肤 + 正文主题 + 文案声音 三者绑定：

- **摸鱼绿系 · 轻快犀利**：头图皮肤 `moyu-green`（内刊报头，绿）＋ 正文用 **摸鱼票据风** 主题（票据视觉，同为摸鱼绿色系）＋ 轻快犀利文案。
- **橄榄手记 · 沉稳深度**：头图皮肤 `olive-journal`（内刊报头，橙）＋ 正文用 **橄榄手记** 主题 ＋ 沉稳深度文案。

`graphite`、`red-white` 保留在引擎 STYLES 里作备选头图皮肤，暂不启用。

**署名**（正文尾部固定）：`我是杰西卡，为你精读海内外一线 AI builder 的一手观察与干货。`

| 风格 key | 状态 | 头图气质 | 文案声音 | 最适配内容 |
|---|---|---|---|---|
| `moyu-green` 摸鱼绿·轻快犀利 | ✅ 启用 | 清新绿、宋体标题、通透 | 口语第二人称、金句密、节奏快、emoji 克制 | builder 观点/演讲、方法论、带钩子的内容（默认） |
| `olive-journal` 橄榄手记·沉稳深度 | ✅ 启用 | 米白+橙、内刊、厚重 | 评论体、长句、书面、克制、少煽动 | 深度访谈、思想性演讲、需要厚重感的话题 |
| `graphite` 石墨冷静·理性克制 | ◻ 备选 | 全灰阶、无衬线、极简 | 分析体、结构化、数据/逻辑导向、中性少情绪 | 技术评测、趋势分析、报告、大会技术 keynote |
| `red-white` 红白力量·观点鲜明 | ◻ 备选 | 正红点睛、宋体、力量感 | 立场强、短句、断言、锋利 | 争议话题、强观点、预测/喊话 |

### 同一篇文章，四种声音的开头示范（证明"文案随风格配合"）

**moyu-green（轻快犀利）**
> 如果你最近也有这种感觉——用 AI 写东西从没这么快过，但产出好像并没有更值钱——那这篇值得你花十分钟。ChatPRD 创始人 Claire Vo 讲了个让全场安静的观点：造东西不再稀缺后，产品人真正的活，彻底换了一批。

**olive-journal（沉稳深度）**
> 当建造的成本被 AI 一路压低，一个被搁置了几十年的问题重新浮出水面：我们究竟为谁而造。Claire Vo 二十年产品与创业的经验，最终收束成一句并不轻松的判断——瓶颈已从"能否造出"，悄然移到了"是否有人真正需要"。

**graphite（理性克制）**
> 本文梳理 Claire Vo 在 Compile 26 的演讲，核心是一个可验证的结构性变化：工程交付量季度增长约 8 倍，而 App Store 的安装、评分、使用量并未同步上升。产能与需求的背离，构成了新的产品约束。

**red-white（观点鲜明）**
> 会写代码，已经不值钱了。这不是耸动，是 Claire Vo 在台上让全场沉默的判断。当人人都能造，"造"本身失去了溢价；真正稀缺的只剩两件事——有人愿意付钱，和你能不能让他们改变行为。

## 四、使用（生成头图）

```bash
python3 render_cover.py    # 渲染全部风格 × 双尺寸到 covers/
```

编程调用（未来创作台按此填充）：

```python
from render_cover import STYLES, render
content = {
  "name":"AI 观察手记", "issue_event":"NO.06 · X 长文精读<br>2026-08",
  "badge":"𝕏 Twitter", "kicker":"<一句副标>",
  "title_html":'标题前段<span class="ul">关键词</span>标题后段',
  "author_html":'<作者>　<b>身份</b> · <补充>', "tag":"深度精读",
}
render(STYLES["moyu-green"], content, "out.png", "covers", shape="wide")   # 或 shape="square"
```

`content` 字段：`name / issue_event / badge / kicker / title_html（含一个 <span class="ul"> 关键词）/ author_html / tag`。
