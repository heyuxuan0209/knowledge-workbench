agent 落地不好，大概率不是模型不行，是你没给够 context。"AI native 组织"换个词就是 agent readable——让公司所有沟通/会议/决策都对 agent 可见。五个可落地实践。

前提：模型已很强，agent 表现不好是 context 问题、不是智能问题。原话"大概率不是它的问题，是你的问题…是 context 的问题"

五实践围绕 agent readable

① 会议三 Level：纪要→自动办待办→agent 入会边开边办（"开会是未来的 prompt"）② 数据分析：agent 扫消息/文档维护"业务动作表"做归因 ③ 招聘两轮法：先禁 AI、再只能用 AI ④ 团队级 agent＞个人助理 ⑤ 先干后学 + 渗透式学习。
